# 숲에서 시작하는 AI · 실습 프롬프트

2026년 10월 12일 국립대전숲체원 강의안(오경희)을 바탕으로 만든 한국어 실습 프롬프트 웹사이트입니다. 강의 순서대로 22개 프롬프트를 제공하며 검색, 원문 복구, 수정 내용의 브라우저 저장, 개별 복사를 지원합니다.

## 실행

별도 의존성이나 빌드 없이 `index.html`을 브라우저로 열 수 있습니다. 로컬 서버 사용 시:

```sh
cd /workspace/ai-lecture
python -m http.server 8000 --bind 127.0.0.1
```

정적 호스팅에는 `index.html`, `style.css`, `app.js`, `prompts.js`를 함께 배포합니다. HTTPS에서 Clipboard API를 사용하며, 지원되지 않을 때는 기존 복사 방식 또는 직접 선택하여 복사하는 방식을 제공합니다.

## 콘텐츠

`prompts.js`에 원본 슬라이드 번호, 단계, 제목, 프롬프트, 사용 안내가 있습니다. 중복 결과 화면은 제외하고 실습·후속 질문을 순서대로 수록했습니다. 프로젝트 테스트는 강의안에 실제 텍스트가 있는 3개만 수록했습니다. 수정한 프롬프트는 현재 브라우저의 localStorage에 저장되며 서버로 전송되지 않습니다. 개인정보를 입력하지 마세요.
